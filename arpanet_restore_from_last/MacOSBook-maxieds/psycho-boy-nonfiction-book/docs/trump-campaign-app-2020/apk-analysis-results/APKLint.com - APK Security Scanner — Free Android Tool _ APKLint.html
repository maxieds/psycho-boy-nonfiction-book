What APK Security Scanner checks * Manifest security flags (debuggable, cleartext, exported) * Hard-coded secrets and API keys in the code * Privacy-sensitive API references * Third-party SDKs and YARA indicators *Good to know:* Static analysis of a single APK — strong for configuration and secrets, but not a dynamic/runtime test. When to use APK Security Scanner Best for A static security-configuration scan of an APK: insecure flags (debuggable, allowBackup), exported surfaces, cleartext traffic, and obvious hard-coded secrets. Not the right tool for Not signature malware matching (use the Malware Scanner) and not a manual penetration test. What you get back A list of security weaknesses grouped by type, each with why it matters and the direction of a fix. How it differs from related APKLint tools It focuses on configuration and exposure; APK Vulnerability Scanner frames the same family as app-owned weaknesses, and the Malware Scanner looks for known-bad signatures instead. Limitations Static analysis catches misconfiguration and patterns, not every exploitable bug or runtime-only issue.
