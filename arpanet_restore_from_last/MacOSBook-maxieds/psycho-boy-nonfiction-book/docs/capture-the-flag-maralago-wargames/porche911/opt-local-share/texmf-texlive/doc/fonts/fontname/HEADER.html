This directory contains files regarding a naming scheme for fonts to be used with TeX. It was used mostly in the early years of TeX. Nowadays it's nearly universal to use the font names as originally distributed.

For the HTML version, click here.

See the ChangeLog file for the version number and changes by release.

fontname.texi is the master source, a Texinfo document describing the overall scheme. fontname.info is the Info version.

The *.map files contain tables of abbreviations and font lists. They are mostly described in fontname.texi.

The *.enc files are encoding files for use with Afm2tfm, which comes with dvips.
