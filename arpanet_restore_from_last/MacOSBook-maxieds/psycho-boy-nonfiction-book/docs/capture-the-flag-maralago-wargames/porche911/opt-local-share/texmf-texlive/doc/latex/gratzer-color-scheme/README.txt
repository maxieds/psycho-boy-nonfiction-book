Introduces the Grätzer-Color-Scheme, Version 1.0, for math publications.

Invoke it with

\usepackage{Gratzer-Color-Scheme}

It colors theorems and corollaries red; lemmas, propositions blue; definitions green.
See example.tex and example.pdf for an illustration.
