numerica-tables allows the creation of possibly multi-column 
tables of mathematical function values in a wide variety of 
styles based on the booktabs package.

Version 3.2.0 requires version 3 of numerica and the booktabs 
package; numerica must be loaded  before numerica-tables. The main 
enhancement in version 3.2.0 of numerica-tables is the ability to 
transpose tables from function values arranged in columns to 
function values arranged in rows. See numerica-tables.pdf for 
details on how to use the package.
