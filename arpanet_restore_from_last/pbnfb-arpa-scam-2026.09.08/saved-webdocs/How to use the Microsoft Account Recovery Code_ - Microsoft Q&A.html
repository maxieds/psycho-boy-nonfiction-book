    How to sign in with a Microsoft account recovery code

    1. Start signing in to your Microsoft account by entering your username at account.microsoft.com/account. ​​​​​​​Sign in
    2. If you don't have access to any sign-in verification method or have forgotten your password, select __Other ways to sign in__​​​​​​​. Note: Some of the following steps may vary, depending on the level of security on your account and the range of numbers or email addresses you have added.
    3. Select Use my password then Forgot password?
    4. Select Use a different verification option then I don't have any of these.
    5. At the Do you have an account recovery code? prompt, enter your recovery code.​​​​​​​ Tip: Recovery codes are not case-sensitive and don't require spaces or dashes.
    6. Once you enter a valid recovery code, you will be given the option to update your password. Note: If your account has two-step verification turned on, you must wait 30 days for changes to take effect. Learn more.

    or generate a Microsoft account recovery code, follow these official steps:

    • Sign in to your Microsoft account at https://account.microsoft.com.
    • Navigate to the Security section.
    • Select Advanced security options.
    • Scroll to the bottom of the page until you locate the Recovery code section.
    • Click Generate a new code.
    • A unique 25-character recovery code will be displayed. You should copy, print, or securely save this code immediately. It is a one-time-use code and will replace any previously generated recovery codes.

    Important Notes:

    • The recovery code is intended to help you regain access to your account if you lose access to your password or authentication methods.

      Question: once you use a recovery code on a microsoft account is it still valid

      No, a Microsoft account recovery code is not valid after it is used. Once you use a recovery code to sign in, it becomes invalid and cannot be used again. Generating a new code will also automatically invalidate any previous codes. 

      • Single-use:

      Recovery codes are intended to be used only once to help you regain access to your account. 

      • Generates a new code:

      When you generate a new recovery code, the old one becomes invalid. This ensures a one-to-one correlation between a specific code and a specific use. 

      • Security measure: This is a security feature to ensure that once a code has served its purpose, it can no longer be used to access the account.

      Hi mark k,

      Regarding your question: If I use the Recovery Code to reset the password, does the Recovery Code expire where I need to generate a new Recovery Code?

      Yes, the Microsoft account recovery code is a one-time-use code. Once you've used it to regain access to your account and reset your password, it becomes invalid and can no longer be used for future recoveries. To maintain account security, you'll need to generate a new recovery code afterward by following the same steps you used initially:

      1. Sign in to your Microsoft account at https://account.microsoft.com.
      2. Go to the Security section.
      3. Select Advanced security options.
      4. Scroll down to the Recovery code section.
      5. Click Generate a new code.

      Notably, kindly remember to store the new code securely (e.g., print it or save it offline in a safe place, not on your sign-in device). Generating a new code will also invalidate any old ones, so it's best to do this right after successfully recovering your account.

      For more details, check the official Microsoft support page: https://support.microsoft.com/en-us/account-billing/microsoft-account-recovery-code-2acc2f88-e37b-…

      If you test this on your account and run into any issues, feel free to share more details!
