Why is the chronos password different from the root password?

My device is a Samsung Chromebook 4.

Most of the answers I find are confusing chronos and root. using the terminal Ctrl+Alt+F2 (right facing arrow) you will be prompted to set a password for chronos (dev pw) by entering

user: chronos 
pw: test0000.

Followed by the command chromeos-setdevpasswd. However, that is not specifically the root password. If you enter user: root there is a completely different password that I have been unable to obtain from online searches.
