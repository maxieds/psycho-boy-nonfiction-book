About the Windows Insider Program

Benefits of the Windows Insider Program

Get early access to the latest Windows features and give feedback

Be the first to preview the new features and updates to Windows and let us know what you think in the Feedback Hub.

Learn what's happening

Learn about the latest program news, updates and insights via flight blog posts, email, and social media.

Connect with the Windows Insider team and community

Engage with Microsoft experts and the worldwide community of Windows Insiders via our social, community forum, and at key Microsoft events.

How to become a Windows Insider?​

1

Join the program

Register for free to join a community of millions of Windows fans who love being on the cutting edge and want to help shape the future of Windows.

Register now
2

Preview Windows

Preview the latest Insider builds and features by running Windows Insider Preview Builds.

Start previewing Windows
3

Influence the future​​

Once you're running Windows Insider Preview Builds, give us feedback on the features, changes, and issues you're seeing in the Feedback Hub.

Provide feedback
